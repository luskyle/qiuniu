为创作而设计

所见即所得

在 VS Code 中直接编辑五线谱；点选、拖拽和调整音符，无需手写 LilyPond 语法。

边写边听

内置钢琴音色和速度调节，播放时高亮当前音符，方便检查旋律与节奏。

预览与导出

使用 LilyPond 雕版预览，并导出多页 A4 PDF。发布包包含相应平台的运行资源。
